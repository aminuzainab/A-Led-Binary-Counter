# A-Led-Binary-Counter
A Led Binary Counter that visually displays the value of 1 to 15(In base 2) using Leds.


It starts from the blue LED to the red LED, when a number is one the led blinks and when it's zero it off.


Components used:

1. A BreadBoard.
2. Jumper wires.
3. 4 LEDs(Blue, green, yellow and red).
4. Arduino Uno(microcontroller).
5. 4 resistors.
